# Personal Expense Tracker

## Introduction
The Personal Expense Tracker is a web application designed to help users manage and track their daily expenses.

## Objectives
- Record daily expenses.
- Organize transactions.
- Monitor spending.
- Help users manage their personal finances.

## Features
- Expense tracking
- Expense categorization

## Technologies Used
- TypeScript
- JavaScript
- React
- Node.js

## Project Structure
- lib: Contains supporting libraries and API-related code.
- package.json: Contains project dependencies and scripts.

## Purpose
This project is developed as part of a college project submission.
